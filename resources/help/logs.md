# Logs

The site's log files: errors, warnings and the records the application keeps of what happened. The page opens on a dashboard; the toolbar leads to the other tools.

## What you can do here

- **Dashboard**: counts by level, entry trends over time, the most frequent errors, and when each was last seen.
- **Log Files**: pick a file and read it, with search and paging.
- **Log Statistics**: the size and entry count of each file.
- **Search Across Logs**: find a word or phrase in every log file at once.
- **Filter Logs**: narrow entries by level and date range.
- **Export Logs**: download a file as CSV, JSON or the original text, or several as a ZIP, optionally between two dates.
- **Rotate Logs**: start fresh files and keep the old ones aside.
- **Archive Logs**: pack older log files away.
- **Clear Logs**, or clear a single file: empty log files.

## Good to know

- Clearing cannot be undone. Export or archive first if the contents might still be needed.
- Rotate and archive keep the old content; clear removes it.
- Large files are read in pages, so a search may take a moment on a busy site.
- Logs can contain personal data such as email addresses and IP addresses. Take care when exporting or sharing them.
- Only files in the site's log folder are listed.

## Common questions

- **Where do I start with a reported error?** Note the time it happened, then use Search Across Logs or Filter Logs around that time.
- **Can I search for one user?** Yes. Search for their username or email address; a user's page also links straight to that search.
