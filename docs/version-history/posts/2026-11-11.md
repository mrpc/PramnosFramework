## Claude as a built-in LLM provider, through Anthropic's Messages API

### Added

- **`anthropic` provider** — Claude Opus 5.5 (the default), Sonnet 5.5 and Haiku 5.5, with a
  million-token context window. It needs `llm_anthropic_api_key`, a key from the Claude Console,
  and is chosen like any other provider (`llm_provider`, a feature's model, a tier, a fallback).
- **`Transport\Anthropic`** — translates the client's OpenAI-shaped requests and answers to and
  from `POST /v1/messages`, so the tool loop, budgets, fallback, streaming and costing work
  unchanged. The system prompt goes apart and a later system note as text in the user's turn.
  Tools go as input schemas and their results as `tool_result` blocks. A forced tool call goes as
  `auto`, because the current models refuse forced tool use. The reasoning setting becomes
  `output_config.effort`. Every request asks for the prompt cache, and a cache read is costed as a
  cache hit. A streamed answer is read from the Messages API's own events.
- **`default_max_tokens`** in a provider's entry: the answer budget when nothing else sets one.
  Claude's is 16 000 because thinking spends from it; every other provider keeps 2 000.
- **Prices** for the three Claude models in `Pricing::SEED`. An installation whose `llm_prices` is
  already saved adds them on `/admin/Ai/settings`.

### Documentation

- LLM guide: a section on Claude: what is translated, and why thinking is not sent back.

## DeepSeek's retired `deepseek-chat` is asked for as `deepseek-flash`

DeepSeek set 24 July 2026 as the end of the names `deepseek-chat` and `deepseek-reasoner`, and
names its fast model `deepseek-flash` (DeepSeek-V4.1-Flash). The old name still answers, with no
notice of when it will stop.

### Changed

- **`Providers::RENAMED`** — a retired model name and its successor. `Connection::model()` returns
  the successor wherever the old name was saved, so an installation that saved `deepseek-chat`
  keeps working when DeepSeek stops accepting it. `deepseek-reasoner` is not renamed, because with
  reasoning off its thinking would be lost.
- **DeepSeek's default and curated models** are `deepseek-flash` and `deepseek-v4-pro`, both
  priced in `Pricing::SEED` with DeepSeek's off-peak half price. `Pricing::forModel()` costs a
  renamed model at the price saved under its old name when it has none of its own.

### Documentation

- LLM guide: retired model names. Upgrade Guide: a row for the new name.
