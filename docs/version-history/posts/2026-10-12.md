## A null date is no date, not today

### Fixed

- `new \Pramnos\Html\Date($name, null)` stores `0`. `getDate()` falls back to
  `date('d/m/Y', $this->date)` when the request carries nothing, and on PHP 8 `date()` reads
  null as now — so the widget answered today's midnight where `0` answers `2`, "no date". An
  admin list passing a never-set `$this->datefrom` and testing `getDate() < 10000` silently
  showed one day of rows; one showed none of 2,852 users, with nothing logged.

### Documentation

- HTML Components Guide: *Date and time* says what `0`/`null` means. Upgrade Guide: one row.
