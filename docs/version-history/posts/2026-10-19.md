## `db:migrate-from-mysql`: the dry run names a backfill time column without an index

### Added

- **`--dry-run --time-column=…` names every table whose time column no index in MySQL starts
  with**, and gives the `CREATE INDEX` to run before the backfill. A backfill window is a range
  on that column. Without such an index, every window reads the whole table, which for years of
  history means days. A column that comes second in a composite index is named too, since that
  index does not serve a range on it.

## `db:migrate-from-mysql --defer-indexes`

### Added

- **`--defer-indexes`**, for `full` and `operational`, drops a migration-made table's plain
  indexes for the load and makes them again once the rows are in.
    - Each definition is recorded in `pramnos_migration_progress` before the index is dropped.
      A load that dies leaves what is needed, and the next run of any phase makes the indexes
      again, with or without the option.
    - Unique indexes and those behind a constraint stay, because `ON CONFLICT` and the keys
      need them.
