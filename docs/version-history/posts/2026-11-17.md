# 17 November 2026

Two entries today:

- A quiet source's message no longer inflates the sidebar/badge unread, on top of counting as due elsewhere (FW-523)
- A reminder posts no line of its own to chat where an application turns `todos.chat` off (FW-524)

<!-- more -->

## A quiet source's message no longer inflates the sidebar/badge unread, on top of counting as due elsewhere (FW-523)

A quiet source's message (`'conversations' => ['quiet_sources' => ['todo']]`, a reminder a bot
posts) was already left out of `Inbox::unreads()` and `Inbox::activity()`'s aggregates — but
`Conversations::forPerson()` and `Conversations::counts()`, which the sidebar and the per-conversation
badge read directly, counted it like any other message. A reminder due in the to-do list then also
showed up as unread chat, on top of whatever already told the person it was due.

### Fixed

- `Conversations::counts()` and the private `unreadIn()` behind `Conversations::forPerson()` now
  leave a quiet source's messages out of the unread count, the same way `Inbox::unreads()` already
  did for its own aggregate. `Inbox::unreads()` no longer re-subtracts them on top — it reads
  `Conversations::forPerson()`'s count, which is already clean, instead of discounting it a second
  time.

## A reminder posts no line of its own to chat where an application turns `todos.chat` off (FW-524)

`Todos::remind()` always posted a "Reminders" line through `SystemPost::post()` wherever
conversations are installed, with no look at `todos.chat` — the same `chat` piece
`Todos::offers()` already gates every other conversations-facing piece of the list by, and the
one `Pramnos\Conversations\Chat` already checks before its own `todolist`/`addtodo` endpoints. An
application with its own todos↔chat integration that turns `'todos' => ['chat' => false]` got the
framework's own reminder line on top of it anyway.

### Fixed

- `remind()` now checks `self::offers('chat')` before posting; the bell and the push are a
  separate, unaffected path, so a reminder is still sent either way — only the extra chat line is
  skipped.
