## The Tailwind theme's "Show X rows" `<select>` was clipped and its open popup had no background

### Fixed

- `.pf-datatable .dataTables_length select` set `width: auto`, which daisyUI 5.7.22's new
  `appearance: base-select` rendering mode sizes to the selected value alone ("10"), not to the
  widest option or the dropdown arrow the theme draws in its background — the digits sat on top
  of the arrow at roughly 26px wide. The rule now sets `min-width: 4.5rem`.
- The same `<select>`'s open popup rendered with no background at all — transparent, floating
  unreadably over the table underneath. `appearance: base-select` opts a `<select>` into Chrome's
  experimental Customizable Select API so the page can style `::picker(select)`, but the theme
  does not style it, and the build this was found on shipped that popup with no background in the
  experimental mode. `appearance: menulist` on the same selector opts this one `<select>` back
  into the plain native popup, which has a background in every browser.
