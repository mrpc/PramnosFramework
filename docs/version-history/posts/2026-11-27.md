## Every Scheduler and Email dashboard tile now opens its screen, not just the first one (FW-587)

### Fixed

`ScheduleStatus::present()` gave `link()` only to the "Late" tile; "Last run failed" and "Running
now" rendered as plain, unclickable `<div>`s. `EmailActivity::render()` gave `$this->link()` only
to "Sent"; "Failed" and "Queued" were the same. A reader drawn to the card by exactly the number
that is wrong — the failed run, the bounced mail — had no way to click through to it, while the
one number that is usually fine (the first tile) was the only one that led anywhere. Every tile
now carries the same `link()` the card's own heading uses; there is one screen behind each card,
not one per tile, so there was never a second link to choose.

### Documentation

No guide change: both widgets' own doc-blocks already describe opening the scheduler/email screen
as the card's behaviour, not one tile's — this closes a gap between that description and the code.
